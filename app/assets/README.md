`alarm.wav` คือเสียงเตือนภัย สร้างจากสคริปต์ `tool/make_alarm_wav.py`

เป็นบี๊บคู่ 2700 Hz ยาว 0.24 วินาที — `AlarmService` เป็นคนคุมจังหวะเล่นซ้ำเอง
(ทุก 0.7 วินาทีตอนเกินเกณฑ์) ไฟล์นี้จึงเก็บแค่บี๊บชุดเดียว

อยากเปลี่ยนเสียง แก้ค่าในสคริปต์แล้วรันใหม่:

```bash
python tool/make_alarm_wav.py
```

| ตัวแปร | ผล |
|---|---|
| `FREQUENCY` | ความถี่ (Hz) — สูงขึ้น = แหลมขึ้น ทะลุเสียงรบกวนได้ดีขึ้น |
| `BEEP_MS` | ความยาวแต่ละบี๊บ |
| `GAP_MS` | ช่องว่างระหว่างสองบี๊บ |
| `AMPLITUDE` | ความดัง 0-1 |

หรือจะเอาไฟล์เสียงของตัวเองมาวางทับก็ได้ ตั้งชื่อ `alarm.wav` เหมือนเดิม
ถ้าใช้นามสกุลอื่นต้องแก้ชื่อใน `lib/services/alarm_service.dart` ด้วย
