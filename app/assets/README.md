ไฟล์เสียงทั้งสองสร้างจากสคริปต์ `tool/make_sounds.py`

```bash
python tool/make_sounds.py
```

| ไฟล์ | ใช้ตอนไหน | ลักษณะ |
|---|---|---|
| `alarm.wav` | เกินเกณฑ์เตือน | หวอกวาดความถี่ 900→2400 Hz สองรอบ ยาว 0.38 วิ |
| `tick.wav` | ทุกครั้งที่นับพัลส์ได้ | คลิกสั้น 9 ms |

`AlarmService` กับ `TickService` เป็นคนคุมจังหวะเล่นซ้ำเอง ไฟล์จึงเก็บแค่เสียงชุดเดียว

## ปรับเสียง

แก้ค่าคงที่ในสคริปต์แล้วรันใหม่

| ตัวแปร | ผล |
|---|---|
| `SWEEP_START_HZ` / `SWEEP_END_HZ` | ช่วงความถี่ที่กวาด — ช่วงกว้างขึ้น = ฟังเป็นหวอมากขึ้น |
| `SWEEP_MS` / `SWEEP_COUNT` / `GAP_MS` | ความยาวการกวาดหนึ่งรอบ / จำนวนรอบ / ช่องว่างระหว่างรอบ |
| `HARMONIC_MIX` | ความ "บาดหู" — 0 = ไซน์นุ่ม, สูงขึ้น = แหลมคมแบบไซเรน |
| `TICK_MS` | ความยาวเสียงคลิก — ยาวเกินจะซ้อนกันตอนนับถี่ |
| `TICK_DECAY` | ยิ่งมากเสียงยิ่งดับเร็ว ฟังเป็น "แคะ" มากกว่า "ปี๊บ" |
| `AMPLITUDE` / `TICK_AMPLITUDE` | ความดัง 0-1 |

หรือเอาไฟล์เสียงของตัวเองมาวางทับ ตั้งชื่อให้ตรงกัน
ถ้าใช้นามสกุลอื่นต้องแก้ชื่อใน `lib/services/alarm_service.dart` และ `tick_service.dart` ด้วย
